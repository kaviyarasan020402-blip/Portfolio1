Data

This data lives only in this browser. To make new items visible to every visitor of the live site, click Export data below, then paste the result into js/site-data.js and re-upload the site. Export data carries titles, categories, descriptions, paths and small images — it does not include large uploaded video files (those stay in this browser's IndexedDB). Use Download video files to grab the actual video files, so you can place them in assets/videos/ and reference their path instead, for a permanent, everyone-sees-it upload.

Publish steps: click the button above → unzip → copy the assets folder and js/site-data.js into your site folder (replace existing) → upload to hosting. After that every visitor (laptop, mobile) sees all images and videos. Needs internet once (loads the ZIP helper).
